# WordPress.org plugin directory assets

Files in this directory are synced to https://plugins.svn.wordpress.org/qrauth-passwordless-social-login/assets/ by the `Deploy to WordPress.org` GitHub Action on every git tag push.

These assets are NOT shipped to plugin users — they only appear on the plugin's directory page at https://wordpress.org/plugins/qrauth-passwordless-social-login/.

## Expected files

- `banner-772x250.png` — low-DPI banner shown on the plugin page header
- `banner-1544x500.png` — high-DPI / retina banner
- `icon-128x128.png` — low-DPI icon in plugin lists
- `icon-256x256.png` — high-DPI icon
- `icon.svg` — optional, vector version (preferred when available)
- `screenshot-1.png` ... `screenshot-N.png` — match the `== Screenshots ==` section of `readme.txt`

PNG or JPG, ≤ 1 MB each. See https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/ for exact specs.
